## How to publish (GitHub Pages)

1. Upload the contents of this folder into the `portfolio/` directory of the `ritikakakkar21.github.io` repository (keep the same file names so existing URLs don't break).
2. Commit and push — GitHub Pages rebuilds automatically within a minute or two.
3. Verify: https://ritikakakkar21.github.io/portfolio/ should now show **ten case studies**, and the two new pages should be reachable at:
   - https://ritikakakkar21.github.io/portfolio/case-09-sportstech-traffic-recovery.html
   - https://ritikakakkar21.github.io/portfolio/case-10-sportstech-geo-guide-engine.html

## Editing notes

- All pages share the same template: header, case hero (metrics + meta bar), numbered chapters, results band, takeaway quote, prev/next navigation.
- Proof screenshots live in `assets/proof/`. Use clean file names (no spaces) when adding new ones.
- Case numbering, prev/next links and the index cards should stay in sync when adding Case 11+.
- No build step, no dependencies — plain HTML/CSS/JS.
